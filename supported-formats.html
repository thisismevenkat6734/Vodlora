Supported Video Formats

Understand which direct video file formats VIDLORA is designed to handle.

1. Currently Supported Formats

VIDLORA is initially designed for direct video file URLs using these formats:

MP4 (.mp4)

MP4 is a widely used video container format. Browser playback depends on the codecs inside the file and the browser's capabilities.

  • Common extension: .mp4
  • Common MIME type: video/mp4
  • Often compatible with modern browsers.

WebM (.webm)

WebM is a web-oriented media container format supported by many modern browsers. Playback depends on the codecs used by the file and browser support.

  • Common extension: .webm
  • Common MIME type: video/webm
  • Supported by many modern browsers.

3. Important: Extension Does Not Guarantee Compatibility

A file ending in .mp4 or .webm is not automatically guaranteed to work. The actual media content, MIME type, codecs, server configuration, and browser support all matter.

4. Browser Compatibility

Use an up-to-date browser for the best experience. Video playback and downloads may behave differently across Android, iOS, Windows, macOS, and other platforms.

5. Server and Network Restrictions

Even a supported video format may fail when:

  • The source server blocks cross-origin browser requests.
  • The video URL requires authentication or has expired.
  • The server does not provide the correct media response.
  • The network connection is interrupted.
  • The browser does not support the video's codec.
  • The source server does not permit the requested download behavior.

6. What VIDLORA Does Not Support

  • DRM-protected or encrypted media extraction.
  • Bypassing paywalls or access restrictions.
  • Unauthorized private or restricted video access.
  • Automatic extraction from arbitrary social media pages.
  • Guaranteed downloading from every video website.

7. Future Format Support

Additional formats may be considered in future versions after compatibility, security, and browser behavior have been evaluated. No future format support is guaranteed.
